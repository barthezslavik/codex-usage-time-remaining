# Privacy Policy

Codex Usage Time Remaining does not transmit, sell, or share personal data.

The extension is injected only on:

`https://chatgpt.com/codex/*`
`https://claude.ai/*`

It renders only on supported usage settings pages. It reads the visible usage/reset information in the page DOM to calculate a local time percentage from the reset date shown by the site. The calculation happens entirely in the browser.

The extension stores only the latest local usage icon snapshot, including provider, reset timestamp, quota percentage, and update timestamp, in Chrome local extension storage. This is used to keep the toolbar icon and badge current.

The extension does not use analytics, tracking, cookies, remote code, external APIs, or third-party services.

This extension is unofficial and is not affiliated with OpenAI, ChatGPT, Codex, Anthropic, Claude, Google, Chrome, or Ko-fi.
